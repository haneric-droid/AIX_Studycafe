## 1. 목표 (보고서 3~6주차 기반)

### 1-1. 보고서에서 정리된 흐름
| 주차 | 핵심 내용 |
|---|---|
| 3주차 | 비대면·무인 창업(스터디카페 등)의 높은 폐업 문제 → 주관적 변수(서비스·마케팅)는 배제하고 **수치화 가능한 외형 변수(유동인구·경쟁 밀도·고정비)** 가 폐업률을 얼마나 결정하는지 파이썬으로 분석 |
| 4주차 | 최종 솔루션 = 예비 창업자가 상권 변수·고정비를 넣으면 **폐업 확률·생존 한계점**을 보여주는 시뮬레이터 (경쟁점 출점·임대료 인상 스트레스 테스트) |
| 5주차 | 주제를 *입지·수급 공공데이터 기반 스터디카페 폐업 리스크 및 생존 확률 분석* 으로 확정. Y = 폐업 여부/생존기간, X = 경쟁점 수, 배후 인구, 임대료 등 |
| 6주차 | 가설: **"경쟁 점포가 과밀한 지역의 스터디카페 폐업률은 비과밀 지역보다 유의하게 높다"** — t-검정 / 로지스틱 회귀 |

### 1-2. 최종 연구 목표
**서울시 스터디카페·독서실의 폐업률(Y)에 영향을 주는 입지·수급 요인(X)을 공공데이터로 찾아내고, 각 요인의 영향 크기를 통계적으로 검증한다.**
이 결과는 4주차에서 구상한 "폐업 위험 시뮬레이터"의 계수(근거)로 쓴다.

### 1-3. 연구 질문 / 가설
| # | 연구 질문 | 가설 (H1) | 관련 X |
|---|---|---|---|
| H1 | 경쟁 밀도 | 독서실 점포 밀도가 높은(과밀) 지역의 폐업률이 더 높다 *(6주차 핵심 가설)* | 독서실 점포 수, 점포 수/수요인구 |
| H2 | 신규 출점 | 직전 분기 신규 개업이 많을수록 다음 분기 폐업률이 높아진다 (기습 출점 충격) | 개업 점포 수(t-1) |
| H3 | 수요 인구 | 10~20대 상주·유동 인구가 많을수록 폐업률이 낮다 | 상주/유동인구 10·20대, 학교·대학 수 |
| H4 | 학원가 효과 | 학원 밀집 지역은 수요가 커서 폐업률이 낮다 | 일반교습학원 점포 수 |
| H5 | 고정비 | 임대료(또는 그 대리변수)가 높을수록 폐업률이 높다 | 임대료 지수, 아파트 평균 시가 |
| H6 | 상권 상태 | 상권 축소 지역은 폐업률이 높다 | 상권변화지표 |

### 3-2. 가장 큰 문제: 링크 목록에 "폐업률(Y)" 데이터가 없음 → **보완 필수**
링크 목록에 있는 데이터는 대부분 X(인구·시설·소비·아파트)입니다. 폐업 관련 데이터는 아래 두 개뿐이고, 둘 다 한계가 있습니다.
- 국세청 100대 생활업종: 사업자 수 재고만 있음 → 폐업 수가 아니라 순증감
- 상가(상권)정보: 점포 ID를 분기마다 추적하면 폐업을 추정할 수 있지만, 파일이 크고(분기당 300MB) 정제 작업이 많음

**→ 보완 데이터 ① (필수, 확인 완료): 서울시 상권분석서비스(점포-자치구 OA-22173 / 점포-행정동 OA-22172)**
- 서비스 업종 100개 안에 **'독서실'(코드 CS200038)** 이 있고, 분기별로 `전체_점포_수, 개업_점포_수, 개업_율, 폐업_점포_수, 폐업_률`을 바로 제공합니다.

- 자치구 파일(550행)은 자동 다운로드 확인. 행정동 파일은 시트 한도 때문에 **연도별 zip 5개(2021~2025, 각 약 1MB)를 직접 받아야** 합니다 → 사용자가 직접 다운로드하거나, 서울 열린데이터광장 인증키(무료)를 발급받아 Open API로 받는 방법 중 선택.
- 이 데이터로 Y(폐업률)와 H1·H2의 경쟁 변수(점포 수, 개업 수)를 모두 만들 수 있고, 나머지 링크 데이터와 **같은 행정동 코드·같은 분기 체계**라서 바로 결합됩니다.

**→ 보완 데이터 ② (권장): 임대료 = 고정비(H5)**
- 보고서의 핵심 X인 임대료가 링크 목록에 없습니다.
- 후보: 한국부동산원 *상업용부동산 임대동향조사* (서울 상권별 소규모 상가 임대료, 분기). R-ONE 또는 공공데이터포털에서 받음(API 키가 필요할 수 있음). 상권 단위라서 행정동/자치구에 매핑해야 함.
- 받지 못하면 대체 변수: 아파트 평균 시가(OA-22164/22163)를 지역 지가 수준의 대리변수로 사용 (한계는 보고서에 명시).

**→ 보완 데이터 ③ (선택, 심화): 상가(상권)정보로 점포 단위 생존 분석**

## 4. 분석 설계

### 4-1. 분석 단위
- **주 분석: 행정동 × 분기 패널** (약 415개 동 × 22분기). 자치구 × 분기(25 × 22 = 550)는 강건성 확인용.
- (심화) 점포 단위 생존 데이터(상가정보).

### 4-2. 변수 정의
| 구분 | 변수 | 출처 | 척도 |
|---|---|---|---|
| **Y** | 폐업률(%) / 폐업 점포 수 | 점포 OA-22172/22173 (독서실) | 비율 / 비율(건수) |
| Y(이진) | 해당 분기 폐업 발생 여부(0/1) | 위와 동일 | 명목 |
| X 경쟁 | 독서실 전체 점포 수, 프랜차이즈 비율, 과밀 더미(상위 25%) | 점포 | 비율 / 명목 |
| X 경쟁 | 개업 점포 수(t-1) | 점포 | 비율 |
| X 경쟁 | 1인당 공급 = 점포 수 / (10~20대 인구) | 점포 + 인구 | 비율 |
| X 수요 | 10·20대 상주인구, 직장인구, 10·20대 유동인구, 야간(21~24시) 유동 | OA-22183/22184/22178 | 비율 |
| X 수요 | 초·중·고·대학 수, 지하철역 수 | 집객시설 OA-22169 | 비율 |
| X 학원가 | 일반교습학원 점포 수 (+ 학원교습소 파일로 검증) | 점포 / 보유 xlsx | 비율 |
| X 소득 | 교육 지출 총금액, 지출 총금액 | 소비 OA-22166 | 비율 |
| X 고정비 | 상가 임대료 지수 (없으면 아파트 평균 시가) | 부동산원 / OA-22163 | 비율 |
| X 상권 | 상권변화지표(4범주 더미), 폐업 영업개월 평균 | OA-15575 | 명목 / 비율 |
| 통제 | 분기 더미(계절성·추세), 자치구 더미 | — | 명목 |

※ 시간 순서를 지키기 위해 X는 **1분기 전 값(t-1)** 을 기본으로 사용.

### 4-3. 분석 단계와 방법
1. **수집**: `requests`로 자동 다운로드하는 스크립트 작성 (행정동 점포 zip은 수동 또는 API 키 사용).
2. **전처리**: 인코딩(CP949) 통일, 분기·행정동 코드 기준 결합, 결측치/0 처리, 파생변수(밀도, 1인당 공급, t-1 시차) 생성.
3. **탐색적 분석(EDA)**: 분기별 개업·폐업 추이, 자치구별 폐업률 지도/막대그래프, 변수 간 상관 히트맵.
4. **가설 검정 (6주차 연계)**
   - H1: 과밀 vs 비과밀 폐업률 비교 → 독립표본 t-검정(Welch) + 비모수 Mann-Whitney U (분포가 치우쳐 있으므로)
   - H6: 상권변화지표 4그룹 간 폐업률 비교 → ANOVA / Kruskal-Wallis
5. **다변량 모형 (요인별 영향 크기)**
   - 음이항 회귀(폐업 점포 수, offset = log(전체 점포 수)) → 발생률비(IRR)로 해석
   - 로지스틱 회귀(폐업 발생 여부) → 오즈비, 4주차 시뮬레이터의 "폐업 확률" 계산에 바로 사용
   - 패널 고정효과(자치구/분기)로 지역 고유 특성 통제, VIF로 다중공선성 확인
6. **강건성 확인**: 자치구 단위 재분석, 국세청 독서실 사업자 수 추세와 비교, 코로나 시기(2021~2022) 제외 분석.
7. **(심화)** 상가정보 점포 단위: 반경 300m 경쟁점 수 → Kaplan-Meier 생존곡선, Cox 비례위험 모형.
8. **결과 정리**: 유의한 요인과 효과 크기 표, 시뮬레이터용 계수 정리, 그래프.

### 4-4. 파이썬 환경
- 설치 확인됨: pandas, numpy, scipy, statsmodels, matplotlib, seaborn, scikit-learn, requests, openpyxl
- 추가 설치 필요(필요할 때): `lifelines`(생존분석, 심화), `geopandas`(지도·300m 반경, 심화), `linearmodels`(선택 — statsmodels로 대체 가능)
