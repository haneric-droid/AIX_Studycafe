# 패널 데이터 변수 설명서 — `panel_dong_quarter.csv`

- 생성 스크립트: `src/02_preprocess.py`
- 단위: **행정동 × 분기**. 기간은 2021Q2~2026Q2(21개 분기)이고, 2021Q1은 직전 분기 값이 없어 제외했습니다.
- 행 수: **8,578행 (419개 동)**. 이 시점(t)이나 직전 분기(t-1)에 독서실이 1개 이상 있었던 동-분기만 넣었습니다.
  - 독서실이 없는 동-분기까지 모두 포함한 버전은 `panel_dong_quarter_all.csv` (8,925행 = 425개 동 × 21분기)
- **시점 규칙**: Y는 이번 분기(t) 값, X(`_L1`로 끝나는 컬럼)는 **직전 분기(t-1)** 값입니다. 원인이 결과보다 먼저 오도록 하기 위해서입니다.
- 출처: 서울시 상권분석서비스(점포·상주인구·직장인구·길단위인구·집객시설·소비·아파트·상권변화지표, 행정동 단위)

## 식별자
| 변수 | 설명 |
|---|---|
| 기준_년분기_코드 | 예: 20243 = 2024년 3분기 |
| 행정동_코드 / 행정동명 | 행정안전부 행정동 코드 (8자리) |
| 자치구_코드 / 자치구명 | 행정동 코드의 앞 5자리 |
| 연도, 분기 | 추세·계절성 통제용 |

## 종속변수 Y (이번 분기, t)
| 변수 | 설명 | 척도 |
|---|---|---|
| **독서실_폐업수** | 이번 분기 폐업한 독서실(스터디카페 포함) 수 → 음이항 회귀의 Y | 비율(건수) |
| **독서실_폐업률** | 서울시가 제공하는 폐업률(%) = 폐업 수 / 이번 분기 점포 수 | 비율 |
| **폐업발생** | 폐업이 1건 이상이면 1 → 로지스틱 회귀의 Y (전체 중 21.8%가 1) | 명목 |
| 독서실_점포수_t | 이번 분기 점포 수 (폐업률 계산의 분모, 모형에서 offset으로 사용) | 비율 |
| 독서실_개업수_t | 이번 분기 개업 수 (참고용, X로 쓰지 말 것) | 비율 |

## 설명변수 X (직전 분기, t-1)

| 시설 | 학교_초중고수_L1, 고교수_L1, 대학수_L1 | 학교 수 (원본 결측 = 0) | H3 |

| 학원가 | 학원_per_독서실_L1 | 독서실 1곳당 일반교습학원 수 | H4 |

## 품질 확인 결과 (2026-10-16)
- 분기별 독서실 폐업 수 합계는 원본과 **정확히 일치**합니다 (차이 0).
- 시차(t-1) 값을 원본과 대조한 결과 불일치 **0건**입니다.
- 결측: 직장_총_L1 210행(11개 동), 프랜차이즈비율·학원_per_독서실 각 25행(직전 분기 점포 0개). 그 밖에는 결측이 없습니다.
- 아파트 시가 결측 6행은 같은 동의 인접 분기 값으로 채웠습니다 (`아파트시가_보간` = 1로 표시).

## 분석할 때 주의할 점
- **이상치**: 둔촌1동(재건축 단지)은 10·20대 상주인구가 2명뿐이라 `독서실_per_1천명_10_20대_L1` 값이 1000까지 튑니다. 로그 변환이나 상하위 1% 절단(winsorize)이 필요합니다.
- 인구·지출·유동인구는 값의 범위가 커서 회귀에서는 log 변환을 권장합니다.
- 상주인구는 1년에 한 번 갱신되므로 같은 해 1~3분기 값이 같습니다.
- 이번 분기 점포 수가 0인데 폐업이 있는 행이 11개 있습니다(마지막 점포가 폐업한 경우). 음이항 offset을 쓸 때는 분모로 `독서실_점포수_L1`을 쓰거나 이 행들을 따로 처리해야 합니다.
- 폐업 수의 78%가 0이라 값이 매우 희소합니다. 그래서 비율에 대한 선형회귀보다 **건수 모형(포아송/음이항)이나 로지스틱 회귀**가 적합합니다.
